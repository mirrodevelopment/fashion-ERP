Authentication 📁 front end/login/login.html
User Login
Every session begins at the login page. Staff enter their credentials (username + password). The system authenticates against the backend and returns a JWT token which is stored in localStorage. Role-based access is resolved here — Admin sees all modules, Tailor sees only production, Cashier sees only payments, etc.
Actions on this page
  • Enter username & password
  • Submit login form
  • Receive JWT token on success
  • Auto-redirect to Dashboard
  • Show error on invalid credentials
Files involved
  • login.html – Form UI
  • login.css – Glassmorphism styling
  • login.js – Auth logic & redirect
  • api.js – POST to /auth/login
What happens in backend
  • AuthController validates credentials
  • BCrypt password check
  • JWT generated with role + userId
  • Token returned in response

CRM 📁 front end/customer/
Customer Registration
New customers are registered with full profile details. The customer's mobile number serves as the unique identifier across the entire system. Existing customers are searched from the customer overview. The Customer 360 view shows a full 360° profile including all their past orders, measurements, appointments, and payment history in one screen.

  • Photo upload (optional)
Customer 360 view

  • Measurement history timeline
  • Payment ledger (advance/balance)
  • Upcoming appointments
  • Quick actions: New Order, Measure
Also consider

  • Assign to specific branch

Measurements 📁 front end/Measurements/
Body Measurements
After registration, the tailor records all body measurements using the Measurement 360 form. These measurements are stored against the customer's mobile number and are reused for every order. The 3D Mannequin Visualizer renders a live parametric 3D body model from these measurements using Three.js, helping tailors visualize fit and identify adjustments before cutting fabric.
Measurement 360 – data recorded
  • Bust / Chest circumference
  • Waist & hip measurements
  • Shoulder width & back length
  • Sleeve length & arm circumference
  • Height & neck size
  • Thigh, knee, ankle (for full dress)
  • Custom notes per garment type
Measurement Overview page
  • Table of all customers + last measured date
  • Search by customer name/mobile
  • Sort by date, name, or completeness
  • Click row → open Measurement 360
3D Mannequin Visualizer
  • Three.js r134 parametric rendering
  • Real-time morph from actual measurements
  • 360° rotate / zoom / pan
  • Fit Score calculation
  • Side-by-side customer comparison
  • Alteration suggestion system
Data flow
  • Saved to DB linked to customer mobile
  • Fetched by order creation form
  • Compared during trial fittings
  • History kept with timestamps

Orders 📁 front end/orders/
Order Placement
The order creation wizard ties everything together — customer, measurements, garment, design, fabric, delivery date, and advance payment — into a single order record. Once confirmed, the order appears on the Production Board and the customer's payment ledger is updated with the advance amount. The Order Overview shows all active orders in a status board.
New Order wizard (6 steps)
  • Step 1 – Search & select customer
  • Step 2 – Select garment type + design
  • Step 3 – Auto-attach measurements
  • Step 4 – Choose fabric & material
  • Step 5 – Set delivery date & priority
  • Step 6 – Collect advance payment
Order Overview page
  • Kanban-style status columns
  • Filter by: status, date, tailor, branch
  • Search by order ID or customer name
  • Priority flags (Urgent / Normal)
  • Quick-update status from board
View Order page (detail)
  • Complete order timeline
  • Linked measurements & design
  • Assigned tailor name
  • Production stage indicator
  • Trial dates & results
  • Payment ledger (advance / balance)
  • Delivery status tracker
Order statuses
  • Pending → In Production
  • In Production → Ready for Trial
  • Trial Done → QC Check
  • QC Passed → Ready to Deliver
  • Delivered / Cancelled

Production 📁 front end/production/
Production Management
The production board tracks each order through five manufacturing stages. A tailor is assigned from the Workforce module. Supervisors advance stages as work completes. Fabric is issued from inventory at the cutting stage. The design sheet (from Design Studio) is displayed to the tailor during stitching. Once all stages are complete, the order moves to "Ready for Trial".
5 Production Stages
  • Stage 1 – Cutting (fabric issued)
  • Stage 2 – Stitching (tailor works)
  • Stage 3 – Embroidery / Embellishment
  • Stage 4 – Finishing & Ironing
  • Stage 5 – Ready for Trial ✅
Production Board
  • All active orders with current stage
  • Filter by tailor / branch / priority
  • Click order → advance stage
  • Assign / reassign tailor
  • View design sheet inline
Production Stages sub-page
  • Detailed stage-level breakdown per order
  • Time tracking per stage
  • Delay flags & supervisor alerts
Integrations at this stage
  • Workforce: tailor assigned here
  • Inventory: fabric issued at cutting
  • Design Studio: design spec displayed
  • Order status auto-updates

Trials 📁 front end/trials-alterations/ · appointments/
Trial Fitting & Alterations
The customer comes in for a trial fitting. The tailor compares the garment fit against the stored body measurements and the 3D mannequin model. If alterations are needed, they are noted with specific instructions and the garment is sent back to production. Multiple trial rounds can be recorded. Once the customer approves the fit, the order moves to Quality Control.
Trial Fitting process
  • Customer visits boutique
  • Garment tried on physically
  • Tailor notes fit issues per area
  • Alteration instructions documented
  • Customer signs off or requests changes
  • Status: Pass → QC / Fail → Back to Production
Trials & Alterations page
  • Trial record linked to order ID
  • Round number (Trial 1, Trial 2…)
  • Area-by-area fit notes
  • Alteration instructions for tailor
  • Result: Approved / Needs Alteration
Appointments link
  • Trial session booked as an appointment
  • Customer notified via SMS/email
  • Appointment links back to order
3D Mannequin usage here
  • Compare garment vs 3D body model
  • Identify visual fit issues
  • Show alteration suggestions on screen

Quality Control 📁 front end/quality-control/
Quality Control Inspection
Before the garment is packaged for delivery, a QC supervisor performs a final inspection covering stitching quality, measurement accuracy, finish, embellishments, and presentation. The result is recorded as Pass or Fail with specific notes. Only a QC-passed order can proceed to delivery. Failed orders are sent back to production for rework.
QC checklist items
  • Stitching quality & uniformity
  • Measurement accuracy vs spec
  • Embroidery / embellishment finish
  • Fabric quality & cleanliness
  • Button / zipper / hook placement
  • Ironing & overall presentation
  • Label & packaging
QC page actions
  • Load order for inspection
  • Rate each checklist item
  • Add inspector notes
  • Mark Pass or Fail
  • If Fail → specify rework area
  • QC record saved with timestamp
Outcomes
  • PASS → Order unlocked for delivery
  • FAIL → Sent back to Production stage
  • QC history visible on View Order page
GET/api/v1/quality-control POST/api/v1/quality-control

Payments 📁 front end/payments/
Payment Collection
Payments are collected in multiple tranches: an advance at order placement, optional mid-installments, and final payment at or before delivery. The payments page shows the full ledger per order with outstanding balance. Receipts are generated per payment. The payment-bridge.js component allows viewing payment status directly inside the View Order page without navigation.
Payment types
  • Advance – collected at order placement
  • Installment – mid-production optional
  • Final – at delivery or pickup
  • Refund – if order cancelled
Payments page features
  • Full payment ledger per order
  • Filter by: paid / unpaid / partial
  • Record new payment (cash/UPI/card)
  • Print/download receipt as PDF
  • Payment history with timestamps
Payment bridge (inline)
  • Shown inside View Order page
  • Shows advance, balance, total at a glance
  • Quick payment button without navigating away
Business rules
  • Delivery only after full payment cleared
  • Balance shown in Customer 360 view
  • Tax/GST calculated from Settings

Delivery 📁 front end/delivery/
Garment Delivery
The final step. After QC approval and full payment, the delivery record is created. The delivery page tracks whether the garment is being picked up in-store or sent out for home delivery. Status is updated in real time: Pending → Out for Delivery → Delivered. On delivery confirmation, the order is marked as Completed and the customer's order history is updated.
Delivery statuses
  • Pending – awaiting dispatch
  • Out for Delivery – en route
  • Delivered – confirmed receipt
  • Returned – customer rejected
  • Store Pickup – collected in branch
Delivery page actions
  • Create delivery entry per order
  • Set delivery type (home / pickup)
  • Enter delivery address if home delivery
  • Update status at each checkpoint
  • Record delivery date & time
  • Mark order as Completed
Pre-conditions (gates)
  • QC must be passed ✅
  • Full payment must be cleared ✅
  • Order status must be "Ready to Deliver"
Post-delivery
  • Order status → Completed
  • Customer 360 history updated
  • Dashboard KPIs refreshed
  • Feedback prompt sent to customer

Supporting Modules
📅

Appointments

Book trial fittings, consultations, and measurement sessions. Linked to customers and orders. Notifies customer via SMS/email.

💬

Enquiries

Capture walk-in leads before full registration. Convert enquiry to customer when ready. Track follow-up status.

📦

Inventory

Track stock levels for all fabrics, threads, accessories. Fabric issued at production cutting stage. Low stock alerts.

🛒

Purchases & Suppliers

Manage fabric purchase orders from suppliers. Received stock automatically updates inventory. Full supplier directory.

Workforce Management

Register tailors and staff with skills & specialization. Track workload, attendance, and performance. Assign to production orders.

🏢

Branches

Multi-branch boutique support. Each customer, order, and staff member is tagged to a branch for filtered reporting.

🔑

Users & Roles

Create system users with role-based access (Admin, Tailor, Cashier, Supervisor). Login audit log. Role controls sidebar visibility.

⚙️

Settings & Company

Configure currency, GST/tax, receipt format, SMS templates, company branding. Settings apply across all modules.

📊

Dashboard

Central KPI hub. Shows active orders, pending payments, today's appointments, low stock alerts, revenue summary, and workforce status.
